# Central de Besteirinhas™

Um mini site de humor com piadas bobas, pensamentos aleatórios e elogios engraçados. Sem romance, só bobagem e sorrisos.

## Como abrir
1. Extraia os arquivos para uma pasta.
2. Abra `index.html` no navegador.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css`, `script.js` e `README.md` para a raiz.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha `main` e `/ (root)`, salve e aguarde o link.

Não precisa de servidor. A fonte do Google Fonts usa internet; o site continua funcionando com fontes alternativas se estiver offline.
